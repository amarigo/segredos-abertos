# Etiquetas de triagem

As skills falam em cinco papéis de triagem. Este arquivo liga cada papel à etiqueta usada nas issues deste repositório.

| Papel em mattpocock/skills | Etiqueta aqui      | Quer dizer                                         |
| -------------------------- | ------------------ | -------------------------------------------------- |
| `needs-triage`             | `needs-triage`     | Quem cuida do projeto ainda precisa avaliar        |
| `needs-info`               | `needs-info`       | Esperando mais informação de quem abriu a issue    |
| `ready-for-agent`          | `ready-for-agent`  | Tudo explicado, pronta para um agente fazer sozinho |
| `ready-for-human`          | `ready-for-human`  | Precisa de uma pessoa para fazer                   |
| `wontfix`                  | `wontfix`          | Não será feita                                     |

Quando uma skill citar um papel (por exemplo, "aplique a etiqueta de pronta para agente"), use a etiqueta da coluna
"Etiqueta aqui".

Se o repositório passar a usar outros nomes, troque só a coluna "Etiqueta aqui".
